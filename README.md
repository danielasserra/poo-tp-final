# 🎲 Proyecto Final – Generador de Personajes D&D (C# – POO)

Este repositorio contiene el proyecto final del **Trayecto Programador**, desarrollado en **C#** aplicando **Programación Orientada a Objetos (POO)**.  
El proyecto consiste en un **generador de personajes inspirado en Dungeons & Dragons**, que permite crear personajes con distintas clases, habilidades y atributos, simulando la mecánica básica del juego de rol.

---

🛠️ Tecnologías utilizadas
- C# 💻
- .NET / Visual Studio 🖥️
- Git & GitHub 🔧

---

📚 Funcionalidades principales
- Clases y herencia: definición de clases base y clases derivadas (Druida, Guerrero, etc.)  
- Encapsulación y propiedades: manejo de atributos privados y públicos  
- Métodos y sobrecarga: ataques, hechizos y acciones de los personajes  
- Gestión de hechizos y habilidades: lista estática de hechizos disponibles  
- Pruebas en Main: creación y simulación de personajes con distintos atributos

---

🎯 Objetivos del proyecto
- Aplicar los conceptos de **POO** en un proyecto práctico y completo  
- Crear un sistema modular y escalable para generar personajes de D&D  
- Integrar técnicas de herencia, polimorfismo y encapsulamiento  
- Documentar y organizar el código siguiendo buenas prácticas
